Stop emitting the unused `old` field on route tokens in the generated registry.

Every token in `.adonisjs/client/registry/index.ts` carried `old`, the whole route pattern repeated once per token, while the client URL builder only reads `type`, `val` and `end`. On an app with ~1100 routes the tokens were two thirds of the generated file (466 kB of 681 kB) and `old` alone was 262 kB; dropping it shrinks that registry by about 38% raw and 40% gzipped with no change in behaviour.

`AdonisEndpoint.tokens` is now typed with `ClientRouteToken`, where `old` is optional, so a registry generated by an earlier version still type-checks until it is regenerated.
